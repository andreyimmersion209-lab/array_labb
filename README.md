# Лабораторная работа № 4. Обработка массивов

## Автор

Хан Кирилл

## Вариант

Вариант 26

## Цель

Освоить работу с двумерными массивами, обход матрицы вложенными циклами и обработку её строк.

## Описание

Программа находит максимальный элемент среди всех элементов тех строк матрицы, которые упорядочены по возрастанию или убыванию. Равные соседние элементы допускаются. Строка из одного элемента также считается упорядоченной.

Для проверки строки сравниваются соседние элементы. Номера подходящих строк сохраняются в отдельном массиве. Программа выводит исходную матрицу, найденные строки в исходном порядке и общий максимум среди их элементов.

## Входные данные

С клавиатуры вводятся:

- количество строк и столбцов — целые числа от 1 до 20;
- элементы матрицы построчно — целые или дробные числа.

Дробные числа вводятся через точку. При ошибке чтения числа или размерах вне допустимого диапазона программа выводит `INVALID` и завершает работу.

## Выходные данные

- `Original matrix` — исходная матрица;
- `Ordered rows` — все упорядоченные строки;
- `Maximum` — максимальный элемент среди найденных строк.

Если подходящих строк нет, вместо строк и максимума выводится `NONE`.

## Пример

Ввод:

```text
3 3
1 3 3
9 5 2
100 4 8
```

Результат после приглашений ко вводу:

```text
Original matrix:
1 3 3
9 5 2
100 4 8
Ordered rows:
1 3 3
9 5 2
Maximum: 9
```

Третья строка не упорядочена, поэтому число 100 не участвует в поиске максимума.

## Как запустить

Создать консольный проект C++ в Visual Studio и добавить `Variant26.cpp`. В проекте должна быть только одна функция `main`. Собрать проект и запустить без отладки: Ctrl+F5. Ввести размеры, затем элементы матрицы.
